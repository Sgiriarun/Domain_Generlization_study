## RQ1 readiness decision

All four datasets contain the signals required for the RQ1 PPG-to-HR study. PTT-PPG has the complete WFDB distribution but not its optional duplicate CSV distribution. No additional PTT-PPG download is required because the WFDB files include all 66 records, ECG R-peak annotations, PPG channels, activity metadata, and participant metadata.

The next implementation step is a common metadata manifest with one row per recording, followed by dataset-specific signal loaders.
