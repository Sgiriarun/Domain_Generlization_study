# Frozen PTT all-pair site-sensitivity outcome

Each comparison uses the same held-out person, activity, recording time, 8-second window and ECG-derived HR.

- pair_1_4: proximal penalty **+2.878 bpm** (subject-bootstrap 95% interval +1.926 to +3.881); positive for **20/22 subjects**.
- pair_2_5: proximal penalty **+2.696 bpm** (subject-bootstrap 95% interval +1.645 to +3.791); positive for **20/22 subjects**.
- pair_3_6: proximal penalty **+1.195 bpm** (subject-bootstrap 95% interval +0.590 to +1.845); positive for **18/22 subjects**.

Positive means proximal input produced more error. This is controlled placement/channel evidence, not a universal anatomical-site claim.
